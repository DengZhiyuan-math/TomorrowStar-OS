## Holistic Repair Decision

### Restore the original supported boundary

Phase 3 should support:

- one local, trusted operator selecting a workspace;
- safe audit IDs and rejection of pre-existing malformed or directly linked audit paths;
- one audit action at a time through the supported CLI;
- atomic snapshot replacement so interruption leaves a readable old or new snapshot;
- pause/resume, immutable original conclusion proposals, and append-only review records
  contained in the validated audit snapshot;
- a deterministic offline default suite and a literal installed-CLI acceptance gate.

Phase 3 should explicitly not claim resistance to:

- simultaneous writers, optimistic compare-and-swap, request deduplication, or retry
  replay across multiple CLI processes;
- a privileged process or same-UID malicious process continuously replacing directory
  entries between system calls or ignoring advisory coordination;
- arbitrary hostile mutation of already-opened directory inodes;
- multi-user authorization, remote storage, or service deployment.

Those are separate concurrency, durability, and security-hardening requirements and
require a future admission decision. They must not silently expand this MVP verification
phase.

### Remove the custom transaction subsystem

Do not introduce SQLite. The user has explicitly chosen to remove work beyond the
original Phase 3 boundary rather than preserve its expanded concurrency contract in a
new implementation. Return to the existing project baseline: Pydantic contracts plus
one schema-versioned JSON snapshot per audit, written with a small standard-library
temporary-file, `fsync`, and atomic-replace helper.

The reduced store contract should provide only:

- safe audit-ID validation and root containment for the direct path before ordinary I/O;
- create, load, and atomic replace of one validated `AuditSnapshot`;
- snapshot-contained inspected facts, answers, coverage, contradictions, attribution,
  original conclusion proposal, and ordered conclusion reviews;
- controlled errors for missing, corrupt, invalid, or directly symlinked audit records;

  been identified.

Remove the following expanded subsystem rather than porting it:

- `fcntl`/`flock`, `.locks`, per-audit lock files, and descriptor/inode rebinding;
- cross-file `snapshot.json` + `events.jsonl` + `accepted-results.json` publication and
