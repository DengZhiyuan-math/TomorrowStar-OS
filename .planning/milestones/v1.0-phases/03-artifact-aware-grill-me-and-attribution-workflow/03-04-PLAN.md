## Lifecycle Transition Table

| Current status | Action | Guard | Next status / effect |
|---|---|---|---|
| active | answer, skip | Exactly one unanswered question; target matches it | active, or reviewing when the last relevant area becomes verified/skipped/unresolved and conclusion is built |
| active | pause | Audit has unfinished coverage and no conclusion | paused, no question emitted |
| paused | resume | Audit has unfinished coverage and no conclusion | active with the next unanswered question; no replayed opening/answer |
| reviewing | review-entry edit | Target exists; entry is not terminal; expected effective hash matches | reviewing; effective entry/hash changes and before/after lineage appends |
| reviewing | review-entry confirm/reject | Target exists; entry is not terminal; expected effective hash matches | reviewing; target entry becomes terminal |
| reviewing | review-conclusion confirm | All entries are confirmed or edited; expected effective hash matches | completed; whole review confirmed |
| reviewing | review-conclusion reject | Expected effective hash matches | rejected; whole review rejected |
| completed, rejected | any new workflow action | — | `AuditWorkflowError`; exact accepted-action replay is resolved earlier by 03-05 storage transaction and never enters this table |
| any status | any action not listed for that status | — | `AuditWorkflowError`, no state/event write |

| Boundary | Description |
|---|---|
| User text/action → pure audit transition | Untrusted multilingual text and action IDs can attempt lifecycle bypass, attribution laundering, or idempotency collision. |
