| CLI input → audit workspace | User-controlled IDs, paths, and actions cross into local persistence. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-03-01 | Tampering / Information disclosure | `AuditStore` paths | high | mitigate | Identifier allowlist, resolved-root containment, symlink rejection, internally derived filenames, and negative tests. |
| T-03-02 | Tampering / Repudiation | snapshots and events | high | mitigate | Canonical hashes, atomic replacement, append-only hash-linked events, verify-before-read, corruption tests. |
| T-03-03 | Information disclosure | audit event logging | high | mitigate | Redacted event projection excludes raw answers and secrets; focused logging tests. |
| T-03-04 | Tampering | artifact inspection | high | mitigate | Treat text as data, accept only manifest-bound facts, never execute instructions or infer capability. |
</threat_model>
