<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| User text/action → pure audit transition | Untrusted multilingual text and action IDs can attempt lifecycle bypass, attribution laundering, or idempotency collision. |
| Documentary fixture → capability conclusion | Non-personal artifact facts must not become personal capability evidence. |
| Original proposal → reviewed conclusion | User authority must affect canonical state without erasing immutable proposal custody. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-03G-01 | Tampering | `transition_audit` lifecycle | high | mitigate | Explicit active/paused/terminal action matrix with regression coverage before any state update. |
| T-03G-02 | Spoofing / Repudiation | attribution classifiers | high | mitigate | Conservative bilingual allowlists, conflict precedence, separated responsibility/assistance rounds, unresolved fallback. |
| T-03G-03 | Elevation of privilege | conclusion basis | high | mitigate | Area answers are capability basis; artifacts remain separately labeled documentary context and never establish ownership/mastery. |
| T-03G-04 | Tampering / Repudiation | conclusion review/action replay | high | mitigate | Immutable action identity, collision rejection, ordered review derivation, retained original proposal/hash/reason. |
| T-03G-05 | Denial of service | malformed fixture references | medium | mitigate | Pre-index referential checks produce controlled audit errors instead of uncontrolled tracebacks. |
</threat_model>
