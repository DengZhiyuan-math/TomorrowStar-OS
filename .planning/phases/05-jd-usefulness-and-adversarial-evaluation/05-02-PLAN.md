## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| raw paste/file -> intake proposal | Untrusted private bytes and instruction-like text enter local parsing and storage. |
| priority input -> route overlay | User preference crosses into a derived application-effort decision. |
| evaluator -> immutable local bundles | Case definitions, baseline arms, attempts, and review packets become retained development evidence. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-05-06 | Tampering | source bytes, paths, spans, and proposals | high | mitigate | Retain raw byte hashes, decode once, disclose controls, reject unsafe paths/links, reconstruct spans, and require hash-bound acceptance through a new run. |
| T-05-07 | Elevation of Privilege | prompt-like JD content | high | mitigate | Treat text as inert data, expose no tool surface, require strict proposal validation and acceptance, and test that injected instructions produce no policy/score/route change. |
| T-05-08 | Spoofing | priority-company identity | medium | mitigate | Use versioned explicit canonical names/aliases, reject collisions and hidden controls, and require user confirmation for ambiguous identity. |
| T-05-09 | Tampering | JD analysis/evaluation store | high | mitigate | Reuse canonical create-only path/hash/atomic-directory mechanics, reject symlinks/undeclared payloads/tampered ancestry, and retain distinct attempt IDs. |
| T-05-10 | Information Disclosure | private workspace, errors, and blinded packet | medium | mitigate | Ignore the runtime root, keep raw text out of routine diagnostics, store only declared payloads, and test the reviewer packet for method-identifying/private metadata. |
| T-05-11 | Denial of Service | oversized or control-heavy local input | low | mitigate | Enforce documented `max_raw_jd_bytes=262144`, accept exact equality, reject one byte over with stable `jd-source-too-large` before any write, and add no dependency or service. |
</threat_model>
