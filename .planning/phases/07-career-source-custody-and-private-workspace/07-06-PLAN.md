<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Private migration request -> committed baseline | Caller enumeration must equal the complete authenticated legacy inventory, not a chosen subset. |
| Retained-output artifact -> successor transformation | Supplied bytes may be missing, substituted, symlinked, or unrelated to the committed output hash. |
| Multiple legacy chains -> one successor stage | Per-source completion or partial coverage could strand unmapped retained history. |
| Retry staging -> later finalizer | Partial files are non-authoritative and may be reused only when byte-identical to the deterministic request. |
