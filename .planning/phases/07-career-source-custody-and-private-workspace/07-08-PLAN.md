<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Semantic path component -> private workspace | A mutable symlink can redirect reads, writes, or deletes outside the authorized root. |
| User-controlled text -> canonical records | Invisible bidi controls can change displayed meaning. |
| Synchronous capture failure path -> raw cleanup | The supported one-process operation must complete committed-plus-working proof before returning; no workspace lock or asynchronous cleanup is assumed. |
| Explicit commit + working manifests -> raw cleanup | Neither mutable working absence, external drift, nor a partial scan proves an object unreferenced. |
| Failure diagnostics -> routine output | Boundary errors must not disclose private paths, bytes, or record bodies. |
