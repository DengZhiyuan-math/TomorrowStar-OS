# Quick Plan: Candidate-Skill Graph Harness Execution Logic

## Purpose

Chart the Wayfinder decision map for deploying the approved candidate-source to
Contribution-Skill assessment boundary into the offline harness. This planning
step makes no product-code or test-suite changes.

## Boundary

- External material may create only candidate skills and source links.
- Only audited Contribution-Skill assessments may affect a user Skill result.
- Private career-data remains out of scope; all future acceptance evidence is
  synthetic and reproducible.

## Workflow

Create the local-Markdown Wayfinder map and its first decision tickets. Do not
resolve a ticket in this charting session.
