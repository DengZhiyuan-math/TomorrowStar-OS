## Question

## Recommended default — pending decision

优先保留单个 worker 与现有可见浏览器。增加最小运行身份、代码版本、最近事件和故障类别；不承诺 worker / 浏览器崩溃后保留 DOM。
优先收紧首页面轮询与页面命令的异常边界，用双页合成夹具验证局部关闭不会结束无关页面。研究只证明存在该源码路径，尚未复现历史退出。
页面局部异常只暂停受影响岗位；浏览器 context 丢失或运行身份无法验证时暂停批次。已核验保存不重复发送；结果未知保留操作并人工核验。安全读取与记录写回的重试分开，不以网络错误自动重传附件。
保留现有 60 秒控制失联宽限作为基线；是否改变由实测决定。自动恢复已确认答案的等待岗位，不改变人工继续整批暂停的规则。

## Resolution requirements

在研究事实基础上，与用户确认新增保证等级，不重复询问人工 Submit 和答案范围。
给出故障矩阵：控制页断连、后台标签、休眠唤醒、单页关闭、browser 关闭、worker 崩溃、重复启动、发送成功后 checkpoint 写失败、原笔记冲突。
每项注明判定证据、暂停范围、可重试动作和验收夹具。零自动最终操作、零未经核验重传、其他正常页面不被局部故障关闭是硬约束。
若保证需要新常驻进程或生命周期拆分，必须给出无法由原生单进程方案满足的具体证据。

## Resolution comment

2026-10-11，用户在本会话明确选择：“先保证单页隔离和检查点恢复（推荐）”。

采用单 worker、现有文件 store 与专用可见 Chromium。正常暂停保留存活页面；单页关闭、崩溃或局部命令失败只停止受影响岗位。context / browser 丢失或共用运行状态无法验证时暂停批次。
worker / browser 退出后以最后成功写入的检查点恢复，重新核验岗位、投递历史、答案范围、PDF、记录版本、当前页面和未知动作；不保证原 DOM 或 browser 在 worker 崩溃后继续存活，不增加独立浏览器进程或自动 CDP 接管。
未知保存、上传与挂接不自动重传。清除 intent 前先保存处理结论；同步重试只处理原记录。暂停批次恢复须明确继续；已确认答案的等待岗位仍按现有条件恢复。最终 Submit 保留人工操作。

工程范围、15 类故障、诊断时限、17 组验收用例与四个开发切片见[稳定性阶段：故障隔离、恢复保证与验收规格](../assets/stability-contract.md)。
控制租约沿用 60 秒，观察过期展示沿用 6 秒；空闲状态更新 2 秒为合成环境工程验收基线，不是 OS 实时保证。实测校准不能降低零自动最终操作、零未知重传、零局部故障误关其他页与零同步重填的硬约束。

本票完成开发前的恢复保证与验收决策。实现和行为验收尚未执行；本轮只更新规格、词汇与地图，检查文档链接、依赖和源码绑定。整体地图仍开放，其他决策票不由本次回复代替解决。
