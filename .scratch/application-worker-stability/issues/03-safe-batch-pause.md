# 03: 控制失联与共同故障后安全暂停

**What to build:** 控制失联、浏览器共同故障或运行条件无法核验时，批次停止新自动动作。用户能看见暂停原因，并在条件恢复后明确继续。

**Blocked by:** [01：区分当前运行与历史检查点](01-current-runtime.md)。需要区分真实共同故障、观察过期与历史状态。

**Status:** closed

**Parent:** [确定故障隔离、恢复保证与诊断验收标准](../../application-worker-next-stage/issues/02-recovery-contract.md)。

**Specification:** [稳定性阶段：故障隔离、恢复保证与验收规格](../../application-worker-next-stage/assets/stability-contract.md)。

- [x] 控制租约沿用 60 秒；超界或时钟倒退后不再授权新的自动写请求。明确暂停请求先到达时立即暂停。
- [x] 控制页转后台本身不触发暂停；租约过期后暂停。重连、返回前台和服务重启均不自动继续批次。
- [x] 工作台退出时，存活 worker 和页面保留；服务恢复不能启动第二份实例。
- [x] 浏览器共同故障在无页面、已暂停和动作中均得到处理；页面状态不再冒充实时可操作。
- [x] 共用运行状态无法核验时，提供阻止新自动动作的停止规则；不以旧磁盘 running 状态解除停止。
- [x] T01–T04、T08 通过；在途请求与暂停后新请求分开计数。模拟时间间隔不冒充真实系统休眠验收。
