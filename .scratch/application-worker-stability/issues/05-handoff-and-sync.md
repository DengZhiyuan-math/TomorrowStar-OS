# 05: 故障后安全接管页面与重试同步

**What to build:** 用户可以接管待核验页面并处理问题；原求职记录同步失败时，可以单独重试同步。自动层不会收回未知接管，也不会重复填表或上传。

**Blocked by:** [02：单页故障后继续处理其他岗位](02-single-page-isolation.md)、[04：保留未知保存与上传结果](04-unknown-action-outcomes.md)。需要局部命令隔离及完整未知动作记录。

**Status:** closed

**Parent:** [确定故障隔离、恢复保证与诊断验收标准](../../application-worker-next-stage/issues/02-recovery-contract.md)。

**Specification:** [稳定性阶段：故障隔离、恢复保证与验收规格](../../application-worker-next-stage/assets/stability-contract.md)。

- [x] 接管先停止该页自动动作，再处理守卫释放和页面显示；接管失败或结果未知不隐式恢复自动改写。
- [x] 人工页面不会因其他页局部故障或正常批次暂停被自动关闭或改写。
- [x] 外部笔记编辑产生冲突时保留原编辑和待同步结果；核验新版本后仅执行同步。
- [x] 仅同步重试期间填值、上传和挂接计数不增加。
- [x] 人工接管、用户确认提交和用户核验回执分别记录；已确认提交拒绝重新填表。
- [x] T07 的接管断言及 T13、T15 的 API、工作台和原生浏览器检查通过。
