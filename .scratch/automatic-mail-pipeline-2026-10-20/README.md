待复核提示接为服务端流程；普通原生启动进入自动申请，纯材料模式显式保留。
后端维持所属 controller 心跳，原生定时提供非提示式权限证明与持久通知提示。

一次流程授权限定本轮邮件范围和既有事实／系统生成 PDF。自动派生发送记录明确为
`workflow_policy`、`actor=system`、`human_reviewed=false`，绑定具体岗位、国家、
分析、输入、PDF 和邮件运行，不假称逐岗材料人审。最终 Submit 不在自动操作集合。

复用既有匹配公式，按已支持分排序，没有新的数值阈值或人工评价表。
重复申请、明确暂缓偏好、完整来源冲突和未知动作继续阻断；不覆盖旧原页。
缺失答案在适用范围自动入库后，确定的填写自动继续。每轮保留原有20分钟窗口。
