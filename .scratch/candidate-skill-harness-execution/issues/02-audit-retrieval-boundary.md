# Define the Audit Retrieval Boundary

Type: grilling
Status: resolved
Blocked by: 01

## Question

Given the candidate-source contract, which existing audit retrieval and
one-question Grill-Me paths should receive candidate Skills as question
selection context, and what exact lineage must prove they never become an
assessment conclusion without an audited Contribution?

## Answer

For the selected Experience Candidate, retrieve its Candidate Skill Links with
the existing inspected facts, limitations, prior answers, and private notes.
Use those links to select coverage and record their identities through the
audit snapshot and conclusion entry that later supports a Contribution-Skill
proposal.

Candidate wording and source context may be shown as an optional recall
reminder in the question or its reason. It must explicitly remain a candidate,
not a premise of capability, responsibility, or mastery. A user who cannot
remember a source's exact text or project detail receives no negative
capability conclusion for that lapse. The existing one-focused-question,
artifact-inspection, and anti-leading guards remain mandatory; later
assessment admission still requires a completed audit, confirmed conclusion,
audited Contribution, responsibility attribution, and evidence basis.
