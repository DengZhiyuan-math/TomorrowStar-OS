## 使用命令

从仓库根、现有锁定环境运行：

```sh
uv run --locked --offline --no-sync python -B scripts/query_tickets.py
uv run --locked --offline --no-sync python -B scripts/query_tickets.py --json
```

`--root <checkout>`可显式指定仓库。默认输出口径、未结案票、依赖、HITL／needs-info、暂停与未知警告；JSON输出包含完整逐票结果。有效输入返回0；结构／声明错误返回2，并清空机械前沿，不能把此时前沿为空解释为工作全部完成。输出始终保留`execution_authorized=false`。

入口：[query_tickets.py](../../scripts/query_tickets.py)。回归：[test_ticket_query.py](../../tests/test_ticket_query.py)。该脚本不导入业务引擎、不写票、不读取私人配置或职业正文，不调用App、浏览器、邮箱、模型或网络。

## 支持范围

- 规范顶层`.scratch/*/issues/*.md`全部实体票；包含没有map.md、由README导航的稳定性目录。排除嵌套历史／快照、夹具及issues目录内README／map／index导航，拒绝跟随符号链接读取外部票据正文。
- 普通元数据、`**Status:** value`和`**Status**: value`。只读取首个二级或更深标题前的元数据，历史正文不能补入当前领取；重复声明报错。领取标签如`Codex / root`原样保留，缺失或空领取保持未知。
- 显式Claim state目前没有本项目已接受的正面状态协议，因此保留未知，不用其自由文字证明可领取；字段缺失兼容原票。缺Blocked by是未知声明，不能当无前置；历史closed／resolved仍保留原关闭状态。
- 同目录唯一裸数字票号、跨图相对链接，以及none／无／无前置和既有明确说明格式。无法解析的混合声明报错，裸编号不能藏在说明分隔符后。含票号说明仅兼容每句单个两位票号并明确以“门槛已满足”或“单独保留”结束的既有处置语法；不从任意自然语言推断依赖。
- 缺失或集合外依赖、歧义票号、循环和活动票依赖行政superseded均显式报错。机械前沿仅按open、明确none、领取已知、依赖声明已知及直接前置实际关闭计算，HITL和暂停仍单独保留。

原发布身份来自既有`publication.json`的canonical_path，不使用其历史状态；当前状态读取原票。当前交付线从原发布身份所在目录推导，再排除同一发布文件的原行政承接及已保留基线／研究身份。没有硬编码23、33、109等时点总数。缺发布身份时对应口径明确不可用，损坏身份报错，不捏造统计。
