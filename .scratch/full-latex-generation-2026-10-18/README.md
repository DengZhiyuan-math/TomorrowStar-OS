# 完整LaTeX岗位版本生成：源码交付证据

规范票为[按 JD 从完整 LaTeX 底稿生成独立岗位版本](../gmail-resume-preparation-2026-10-17/issues/21-generate-full-latex-job-version.md)，唯一产品契约为[已确认完整CV契约](../gmail-resume-preparation-2026-10-17/issues/18-full-cv-review-contract.md)。本目录只保存合成验证、修改前字节、候选范围与审核证据，不存个人资料。

## 交付范围

正常准备任务在分析后明确绑定底稿；原独立LaTeX读取、归档和限制继续复用。独立新版本保留完整源、原／新主文件、输入和历史；底稿不变，没有四条上限。模型将全部原正文映射为采用、相关性省略或待核对组，保留原文、改写、来源、归属及理由。省略原文可供后继Prism编辑恢复；待核对陈述不能自动恢复进正文。

既有来源及适用已确认身份记录会被检索引用；教育和履历日期只作有定位的背景，不建立个人贡献或能力。信息库无单独记录不等于无来源。冲突、责任不清及机械可见的无依据数字／日期进入待核对清单；机械核验不证明语义忠实。生成的正文仍全部待用户分组审核。

生成仅保存待审源版本。通用草稿审核、PDF导出和材料确认对新origin继续阻止，后继[Prism分组审核](../gmail-resume-preparation-2026-10-17/issues/22-prism-grouped-factual-review.md)及[新PDF确认](../gmail-resume-preparation-2026-10-17/issues/23-confirm-reviewed-latex-pdf.md)尚未实现。已安装App未更新，组合／安装仍由[当前候选整链](../gmail-resume-preparation-2026-10-17/issues/19-current-candidate-journey.md)持有。真实申请继续暂停。
