# 材料15：限定真实试点结案

用户要求完成真实批次去重和可用性验证，并复用已有事实及精确 PDF 的接受记录。本票在原批准的单样本材料范围内结案；不代替准备版整体接受、浏览器人工验收或新岗位自动生成验收。

## 已验证

- 安装版对相同账号、固定历史 UTC 范围和有限真实邮件页进行了两次读取。邮件身份与内容一致；读取顺序变化不影响身份。推荐身份唯一，原推荐 ID 和来源消息集合保留。
- 重复更新没有新增申请记录、任务、简历生成或 PDF 编译。既有事实、原用户决定、精确源与 PDF 保持不变。
- 原用户接受时间、原话及原回执引用已登记到独立材料接受回执，操作登记时间另记。App 显示此版本已接受，不要求重新审核同一事实或同一 PDF；资格及内部生成审核语义没有提升。
- 从安装版将现有已接受材料直接纳入暂停批次。同一请求和新的重复请求均复用同一材料批次；重复原请求不改写记录。
- 冷重开后，任务、接受回执、批次、请求和 PDF 相同。批次停在等待投递结果记录，推荐读取也没有自动继续。
- 原未知导出及暂停记录保留。批次不能借用材料接受来恢复编译、生成、填写、上传或 Submit。

首次真实读取曾因 Gmail profile 的当前字段名不兼容而停止，没有读取邮件。旧失败记录保留；兼容修复支持当前及旧字段名，并继续拒绝账号字段冲突。后继真实双读已通过。

## 使用办法与保留边界

打开已保存材料，使用“将此已接受材料纳入暂停批次”。已采用后直接查看现有批次和 PDF；重开只读，不会自动继续。已有接受记录无需再次确认。

本次有界读取仍有未读后续页。无全文、取源失败、历史已知失败和未知停点均已计入私人结果清单，没有当成可用完整 JD。未验证新岗位自动 CV 或普通后续批次的生成链。原未知历史仍硬性阻止执行；这些例外不因本票结案而解决。

材料15的后续可用性结论仅覆盖已接受材料的批次建立、复用、幂等和冷重开。材料16及浏览器HITL保持开放。真实申请、填写、上传与最终 Submit 继续暂停。
