## 输入输出与验收标准

### P01：主要正文和自动目录

输入为既有职业经历、关联仓库/论文/资料，以及基础信息记录；只整理保存内容，不重新评定可信度。经历固定 ID，正文保存身份/角色/日期/状态、目标、工作、方法技术、合作与结果；大经历按子项目分节。目录由正文及关联内容生成，基础信息库只提供统一入口。

源码入口已接入既有 `CareerLibrary`，由 `career_experiences` 保存正文、派生目录及历史，CLI 为 `scripts/run_career_experiences.py`。合成回归覆盖正文与关联内容取词、增量更新、重命名、人工更正、同文副本/导出去重、独有批注、生成材料排除、失败可见和安全读取。私人正文未整理，以下真实数据接受不因源码检查通过而自动勾选。P03 的长目录分段消费、P04 已有源码与合成契约检查，真实语义判断及后续全链路保持各自待验范围。

- [ ] 首次现有条目都有可发现入口；新增/改名/移动/更正/资料关联变化只更新相应条目，独特事实和历史保留。
- [ ] 摘要、技术/领域/任务检索词、关联与详情入口来自实际内容；标题不含 Python 仍可命中正文/仓库记录，Crossfield Lab（合成名）等跨领域条目可从工作内容发现。真实记录只在私库验证，公开回归用等价合成。
- [ ] 同内容 TeX/PDF 与复制件只索引一次；日志/依赖/导出不平铺，具有独特内容的补充资料可读取。生成简历不循环入库成事实。
- [ ] 目录整理失败不隐藏经历；已确认自述、无考试与未完研究审核均不触发应用降级。明确用户更正生效，只有无法解决的实际事实矛盾才集中询问。

### P02：一次岗位说明

输出 `job_brief` 和要求清单，含业务对象/目标/产出、原子要求、原组关系与固定权重。模型可提出框架和短理由；数值、组内分配与路由阈值在本步用固定样例明确，不沿用未确认的常量作为新设计结论。区间路由不得仅因未知导致下限较低就自动记低匹配并跳过。

源码已接普通两库分析入口。`application_job_brief` 在资料读取前持久化一次解读；检索、匹配、事实更新复核与写作复用。权重归一 100，AND/OR 及复合分支按原关系聚合，部分支持与未知保留区间，硬性资格独立汇总。沿用无数值自动跳过策略。详见[规则与边界](../../docs/job-brief.md)；以下勾选仅表示源码与合成验证，真实岗位语义未接受。

- [x] Quant Research 合成样例围绕金融业务产出，固定业务 80/方法 20；关键词次数不改组权重，不添加 JD 未列的实盘/盈利门槛。
- [x] 复合要求拆分后组总权重守恒；重复句不重复加分；下游消费同一说明，不能更改要求、目标、关系和权重。
- [x] 原 AND/OR 及嵌套替代资格在流程、解释和展示中保持原关系；失败或未知尝试保留，不在同版本目录隐式再次解读。
- [ ] 真实岗位模型的业务解释及私人案例语义接受。

### P03：检索一次交付

消费岗位说明、适用基础事实和完整轻目录，交付相关事实、正文/必要补充原文及引用入口。当前每岗完整读目录，不固定 top-K、不整库原文拼接，不新增向量依赖。

源码已通过正常两库入口接入固定 `material_packet`。目录项分片保持候选 ID 与重叠上下文，真实 pending/标题项先读正文；按需展开关联并分段阅读长资料。业务目标与要求分别保留查找方向，所有片段及原文定位保留。读取、引用或预算执行失败不生成匹配分。写作者只收到其分配来源子集，不使无关片段全局失效。见[操作与边界](../../docs/material-packet.md)和[P03 验证记录](p03-source-verification.md)。下列勾选仅表示源码与合成回归，真实私人案例未接受。

- [x] 业务目标和全部要求有查找覆盖；同一经历多用途合并，关联仓库/论文正常展开；长资料分段，无静默截断。
- [x] Crossfield Lab（合成名，真实条目留私库）、Python、语言案例经正常入口发现和读取；改项目名、去掉能力同名标签仍保留内容相关性，不用手工名单或逐 JD 特判。
- [x] 索引待补或只有标题的目录条目，先补该条索引或回退读正文；无法取得时为执行未完成，不能静默判不相关。
- [x] 已读、未发现记录、读取失败/尚未完成明确区分；后者不转申请人 unknown/gap、不产生看似完整的低分。
- [ ] 真实私人经历、真实模型召回与语义接受。

### P04：匹配与推断契约

消费 P02/P03 交付的固定结果。直接记录/确定性推导/语义推断输出要求 ID、事实引用、判断、关系、短依据与表达范围；程序核对接口/计算，不增加第二审核模型，不写永久信息库。

- [x] 无同名字段仍能从实际工作推断跨学科、交流、合作和技术经历；明确自述直接接受。精确等级/数字/角色不能凭空补造。
- [x] 资料不足输出区间，结论完整输出单分；资格单列、资料覆盖与简历覆盖独立。明确事实不符才判不满足，执行/引用错误单列。
- [x] 换简历选材/篇幅/顺序不改背景分，重复文件不增分。词汇改写、无考试、未完审核的离线正反/变形测试通过；JSON Schema 不冒称语义正确证明。
- [x] 普通界面一屏快速看懂业务适配、优势与待补，逐句/公式/内部引用折叠，内部批次与无关岗位清单不常驻。

源码与合成检查见 [P04 记录](p04-source-verification.md)；录制语义结论的离线测试不等于真实模型语义质量。

- [ ] 真实私人材料、真实模型推断及用户语义接受。

### P05：写作—组装—唯一内容终审

主 agent 消费固定 `job_brief`/匹配/推断/资料包/人工底稿，交付写作计划。分经历写作者输出分配块的 TeX 与使用引用；主 agent 负责全局块。程序按计划组装，单一独立终审只比较新生成表达与上游已交付内容。

- [x] 使用实际 subagents 验证分工；写作者不重复判断岗位、推断或经历可信度，不提交“实际读取即可信”的批准报告；组装不语义审查。
- [x] 终审可输出局部文字/结构补丁，程序应用后绑定最终候选；实质改写或缺细节只退回对应片段。部分失败不重跑成功片段，人工修改/省略/固定块保留。
- [x] 不把匹配预选来源作为简历可用来源上限，不回写匹配分；下游不重扫实时库来判固定输入失效。

源码与实际 subagent 合成验证见 [P05 记录](p05-source-verification.md)，不代表真实私人简历质量或安装版接受。

- [ ] 真实私人材料写作与用户质量接受。

### P06：Prism 编辑与 PDF

- [x] PDF 区可“在 Prism 中编辑”；进入后系统停止写该 TeX，明确“完成编辑，返回校对”才接回，不靠关窗猜测。
- [x] 人工返回仅拼写/语法/大小写/标点/重复词快速校对；无内容质疑、润色、事实修改、排版调整或 TeX 命令修改。歧义只提示，补丁可回看，人工意图优先，不进入 AI 内容终审。
- [x] 使用 Prism 已成功编译结果，不重复编译；有未导出修改/失败/未知时保留上一版终稿。迟到结果不覆盖新版本；旧 PDF 可读而非全局 stale。
- [x] JD、两库、App/模型/提示词/登录元数据或编译器变化不使已保存终稿失效；源对应检查只涉及 TeX 与实际依赖，输出文件自身检查完整性。生成新 PDF 不伪称已替换网站附件。

源码、完整默认离线回归、隔离浏览器及独立审查见[P06 记录](p06-source-verification.md)。上列勾选仅表示源码与合成验证；Prism 源码补丁已应用，运行服务未更新或重启。

- [ ] 运行中的真实 Prism 服务与私人文稿校对质量接受。
