## Question

新的安装版是否实际加载本次实现，并能在真实原生窗口完成隔离合成链，而非仅源码测试通过？

## Work and reuse

- 先只读检查安装版/运行中的任务和原页；如存在需保留的运行，不强行退出或更新，记录明确阻塞。
- 使用现有 macos/build.py、verify.py 和固定可核验运行时，在新输出位置构建；保留原安装包完整回退。
- 合成验证通过后更新用户的 TomorrowStar 安装；核对 bundle/build 清单、实际进程加载版本与持久状态。
- 通过 App 窗口操作合成 JD→评分→简历→填写待复核；不能直接调 API/脚本冒充原生 UI 验收。
- 首次启动、CLI、资料目录、PDF、浏览器与原生权限逐项观察。权限需要用户授予时保留未通过状态，不自动扩权，不用别的宿主替代。
- 合成与真实运行分开；本票不读取 Gmail 或对真实招聘网站填值。

## Ownership

- `macos/build.py 与 macos/verify.py（复用）`

- [x] 可定位新构建与回退包，签名/清单和实际加载版本一致。
- [x] 安装版 App 实际完成合成链至待人工最终复核；有原生 UI 观察证据。
- [x] 旧运行/页面/附件/配置未被覆盖；权限或启动阻塞未解决时本票不得按源码通过关闭。
