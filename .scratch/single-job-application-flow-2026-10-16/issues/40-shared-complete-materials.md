## Acceptance criteria

- [x] 默认申请复用现有完整材料生成、编译、导出和检查路径，不再受旧四项摘要路径限制；材料准备与Prism继续可编辑、预览和调用共享能力，未受影响的有效产物直接复用。
- [x] 普通岗自动获得针对性简历及当前确实必要的材料初稿并完成技术检查，无逐组/逐草稿/逐PDF批准；高价值且高匹配先完成分析与完整初稿，交主编排请求精准调整。
- [x] 选材、措辞和必要附件基于已有事实；教育复用固定记录，团队责任、计划/完成状态及来源正确；不因取消人工审批而编造内容。雇主材料无需额外AI来源披露。
- [x] 人工修改的版本作为后续更新基础；只重算事实模块判定实际受影响部分，无关资料或模型配置变化不使完成材料失效。当前采用文件与岗位的关系继续可核对，不另造批准对象。
- [x] 保留原稿、来源、历史版本、阶段intent/attempt与保存/采用恢复；生成或编译失败显示具体原因，已有有效结果不重做，外部结果不明先核对，不盲重试。
- [x] 通过已有公开材料入口回归普通自动、高价值初稿、人工编辑后更新、必要附稿、复用、局部变化、编译失败及重开。固定测试PDF只证明测试运输；不能充当真实内容或排版验收。
- [x] 列明被移除的重复生成分支、普通审核按钮/条件及其旧断言。实现关闭不等待真实用户质量评价，不将真实内容验收冒称已经完成。
