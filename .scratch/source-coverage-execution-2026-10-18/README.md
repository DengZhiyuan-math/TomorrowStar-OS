# 既有资料覆盖与单岗选择依据：执行核验

2026-10-18。用户授权执行[核验既有资料覆盖与单岗选择依据](../gmail-resume-preparation-2026-10-17/issues/17-source-coverage-and-job-selection.md)，复用已有资料，真实申请继续暂停。本轮只解决这一张核验票。

结论：既有来源足以进入有边界的人工材料审核。当前岗位应称为**选定试点**；现有记录不足以证明跨岗位最高匹配。核验不是资格确认、材料接受、职业清单后继接受或个人能力评估。

## 已核对的边界

- 运行中原生后端使用的职业资料和申请目录与当前保存配置一致，采用材料准备模式。此次审计涉及的扫描、取材、信息库、状态与匹配模块均与安装包磁盘源码一致；此检查不冒充运行中进程的内存代码证明。进程参数展示中的带空格路径按已知参数边界核对；没有把初次错误拆分当成目录故障。
- 已复用既有简历、经历目录、已确认身份及当前信息库。信息库未收录只表示该证据通道没有记录，不能说个人事实不存在或要求用户重新提供已确认且仍适用的事实。
- 当前扫描只覆盖既定目录中的非隐藏Markdown／JSON；文档读取成功、履历选材许可、身份确认、责任归属和资格审核各有边界。不能以文件扫描覆盖代替完整职业资料覆盖。
- 超出读取上限的文档保留未读原因。没有放宽上限、自动补造事实或将未读文档视作缺学历／缺能力；完整来源、读取状态、归属和适用性清单只保存在所选私人核验报告。
- 当前技术导入任务没有新分析，事实审阅仍待处理。历史分析整体来源版本不再匹配，部分取材原文亦已变化；旧分数不能当当前分数或跨岗排名。保存的JD不代表本轮已向外站核实岗位仍开放。
- 技术导出、旧材料批准及旧unknown任务各自保留原范围，没有迁移批准、重新绑定分析或恢复申请。
