## 当前实现契约

- 主入口只需粘贴JD或岗位链接；Gmail沿已有显式读取链取得来源，完整JD自动保存。
- 输入原文、来源和提取结果保持可回读。后台状态持久化；断连或写入结果未知先核验，不重复创建。
- 公司、岗位、地点、时间、薪资等事实须有原文支持；缺关键事实保存待补来源，不编造公司或申请URL。
- 个人偏好复用已有明确记录。能力匹配与个人主观评价不从JD编造，本轮不读取职业材料。
- 岗位详情默认只读摘要、原文、来源及缺失信息；旧表单作为可选更正，保留revision与冲突处理。
- 正常填写入口自动核对技术条件；未知外部结果仍停止，不自动恢复旧任务。原生检查不提示、不改变TCC。
- 网站复核使用现有worker保留的准确原页。主界面显示处理状态、必要问题及去原站复核；诊断折叠保留。
- 真实申请继续暂停，发送范围仍需一次明确用户动作，最终Submit仍由用户执行。工程验证使用合成数据、现有唯一主App和固定签名。
