# 具体引用与本地自动流程简化

本轮以当前 HEAD 为审计基点，保留既有未提交工作。后续用户明确要求减少审批和机械语义门禁，取代早期复核中主张硬拒分析的建议。

- 匹配引用具体资料条目和原文，保存实际字段位置；不再提供整份文档的引用编号。
- 单项来源或归属问题标记未知，保留原模型输出和有效来源；其余判断继续保存、计分。
- 学历语义由模型结合原文与 JD 判断；移除“在读”等关键词硬拒分析的规则。
- 自动申请允许资格未知时继续准备，未知仍保留；表单缺必要事实时补充。明确冲突保持提醒，最终 Submit 由用户操作。
- 自动流程主界面显示进度；旧手动操作和发送确认移至折叠工具区，不作为后台自动流程的必经步骤。
- 填写中补充事实沿用已有自动入库通路。
