HTML 在这里仅指招聘网页上的输入框及 maxlength 属性。求职信可向网页提交纯文本，也可按页面要求生成 PDF；内容仍保存为 JSON，文件仍由 LaTeX 生成 PDF，没有恢复 HTML 简历生成链。

旧 v3 若已保存为一般未知结果，却没有可靠的未分派证明，不能仅凭缺少 export-intent 认定零调用；这类旧记录继续等待核验，不自动重放。
新的预检失败具有明确证明，可在条件修正后按正常流程恢复；只读重查不伪造未发生的编译。
