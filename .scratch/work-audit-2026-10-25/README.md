默认 Pipeline HTTP 入口另有当前岗守卫；已确认可达范围为独立材料准备入口和公开程序调用。

**P2：默认流程等待时，非当前岗位仍可刷新匹配。**

`application_pipeline.py:169–199` 的公共准入没有对 `flow:refresh-match` 安装当前岗位检查；`application_match_refresh` 只核对目标任务自身。合成公共接口反例中，B 仍为当前岗并等待用户，A 的匹配 callback 实际执行一次并保存新回执，Pipeline 状态原字节保持。A 可来自已经 skip 但仍保留完整材料的旧岗。

反例复用了材料准备夹具，并显式设置合法 application 模式及默认队列等待快照；公共 HTTP 使用相同的准入／Flow 调用组合，但本轮没有实际发送该 HTTP 请求或走完整原生界面路径。第三轮另用公开 `Pipeline.request("skip")` 形成 A 的保留状态，再复现同一缺口；B 的等待快照仍为合成输入。这些证据不构成真实模型或安装版验收。
