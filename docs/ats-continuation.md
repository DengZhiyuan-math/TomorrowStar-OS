# ATS 解析接续与差异选择

P07 的源码行为与接受边界见[验证记录](../.scratch/resume-agent-delivery-2026-10-22/p07-source-verification.md)。
P08 的正常两库至人工材料和保留真实绑定的隔离 ATS 组合见[组合交付](combined-delivery.md)。
本页描述普通单岗位的字段接续；[产品规范](single-job-flow.md)和
[开发计划](development-plan.md)持有完整流程。最终 Submit 继续由用户操作。

系统先保存原页、当前步骤的非空字段和附件基线，再必要上传。上传结果与解析
状态分别保存。已有附件按实际内容或平台绑定核验，同名不代表同一 PDF。
上传、填写及中间导航执行前重读现场，完成后读取实际值；现场变动时停止该次
写入，保留原意图和当前值。不会另建申请来回避未决结果。

解析明确活动时停止系统写入。明确结束后仍观察字段与附件稳定；无结束信号则
使用连续稳定窗口。当前保守默认参数为采样间隔 0.25 秒、至少三次样本，明确
结束后静默 0.5 秒，无信号静默 1 秒。具体解析观察连续 30 秒仍无法稳定时暂停。
这些参数经隔离延迟样例验证，不是任意网站的完成保证或整轮执行时限。继续监测
迟到填充；原生人工输入也会暂停写入，单次 Continue 后重新观察原页。

电话、无歧义日期及邮箱域名等价格式不产生差异。系统只自动补空白。既有非空值、
网站改写的受保护值，以及无法证明由解析器产生的无效非空值，均集中显示当前值、
资料值、基线和可知来源。用户可一次选择保留、采用或手改，再点击 Continue。
选择仅作用当前申请，不写回两库。现场值、来源、建议值或文档身份变化时不能
沿用旧选择；同 URL 刷新也采用新文档身份。

未知动作先观察同一运行、原页、文档、步骤和字段。目标值与保存证据相符时接续；
明确未发送时可重新计划。明确未发送，或同步输入已经返回，且解析稳定、没有平台保存仍在途时，
第三种值才可结算为被后续值替代，并进入集中差异；原意图与观察历史保留。
仍在途、缺保存证据、旧协议或身份不明的动作继续待核对，不以超时推定失败。
附稿核对使用其原字段和附件身份，不能拿简历附件替代附稿证据。

准备提交前及实际交接前均核对必填、页面校验错误、附件版本、重要差异、解析
状态和未知动作。就绪页迟到改写会撤销当前就绪状态，但保留材料与历史。明确
人工接管不冒称核验完成。只有已识别的中间 Next/Continue 可自动执行；最终按钮、
Enter、`form.submit` 及最终网络提交不由自动执行者触发。

接口沿用单岗 `worker-action` 和 WorkerService，新增批量
`resolve-form-differences`。请求绑定 `application_id`、当前 `binding`、`revision`，
以及 `choices` 列表；每项含 `difference_id`、`action=keep|use|edit`，`edit` 另含
`value`。保存仅记录选择，不恢复执行。旧动作的人工核对入口继续保留。

当前离线与隔离浏览器证据不代表真实 ATS、私人字段质量、安装版或自然 Submit
后的结果接受。本轮不构建、安装或重启主 App。
