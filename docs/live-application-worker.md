## 旧试点启动与使用

先在工作台选择已有私有资料夹。浏览器安装方法见[合成预览](lever-worker-preview.md)。
从 checkout 启动真实模式：

```sh
uv run --locked python scripts/run_career_portal.py \
  --port 8769 \
  --worker-root "$HOME/Library/Application Support/TomorrowStar/application-worker" \
  --worker-live --worker-cdp-port 9231 --open
```

1. 在求职进度勾选最多三个“准备投递”岗位。每条记录须有 Lever 或 Greenhouse 直达链接。
2. 逐岗位确认申请国家，默认生成并核验岗位简历草稿。已有不超过 700 KB 的 PDF 是可选入口。系统固定文件内容版本。
3. 准备批次，再点击“开始／继续”。系统只填写已确认且适用范围匹配的答案。
4. 集中补充未知问题。默认保存到真实答案库，并在确认范围内复用。其他岗位继续处理。
5. 填完后“接管并复核”，在保留的招聘页面检查内容并人工 Submit。
6. “我已人工提交”只记录用户确认。接收来源另行记录，两者保持区分。

没有核验生成草稿或选择已有 PDF 时不能准备批次。系统不导入合成答案，不从职业资料猜测申请答案。
暂停批次保留页面。控制页面失联会在既有宽限后暂停；重连后手动继续。

## 页面与附件

`hosted_ats.py` 读取固定 DOM 标签与原生控件。它核验 ATS、岗位路径、公司和页面标题。
执行支持文本、原生选择列表、单个确认选项的 checkbox/radio，以及匹配唯一标签的 ARIA combobox。
动态选项不唯一、标签变化、登录或验证会暂停该岗位。

| 平台 | 当前附件路径 | 提交前的限制 |
| --- | --- | --- |
| Lever | 原生文件选择触发同站点 `/parseResume` | 核验同站点、multipart 的 accountId/resume 结构及当前 PDF 字节，不再消费上传 grant。独立检查拦截已知最终申请请求；未知用途保留原页等待核验。 |
| Greenhouse | 当前验证的托管表单使用 `data-allow-s3=false`，附件留在本地控件 | 支持文件选择后的 React 控件替换。未实现 S3 预上传；遇到该路径暂停岗位。 |

这些限制由 worker 的浏览器 context 执行。新页面同样受约束。
所有平台的受管页和未归属新页均拦截 WebSocket；人工接管前不连接服务器。
人工接管会撤销该页的自动处理，并允许用户使用网站的原生请求。
worker 没有 Submit、Enter、`form.submit()` 或最终投递 HTTP 动作。

2026-10-20 源码已退役上传 grant 消费：Lever 原生 `/parseResume` 校验同站点、
multipart 结构及当前 PDF 字节；最终申请请求由独立限制拦截。
这不证明新源码已安装或真实上传验收完成。旧活动页和 grant 文件保留。

以下为历史配置。旧版 Lever 上传前，操作者须从该岗位的公开 ATS 资料核验实际账户身份，并在私有 worker
运行目录的 `lever-upload-grants.json` 保存精确许可。不能从上传请求本身或岗位路径猜测账户 ID。
文件格式如下；每条 `job_url` 须是规范化的 Lever 岗位直达链接，不含 `/apply`：

```json
{
  "schemaVersion": 1,
  "grants": [
    {
      "job_url": "https://jobs.lever.co/synthetic/00000000-0000-0000-0000-000000000001",
      "accountId": "operator-verified-public-account"
    }
  ]
}
```

旧版许可只适用于列出的岗位。当前源码不再读取该文件，也不要求为迁移重启已有原页。

Greenhouse 文件控件被替换后，页面只能回读文件名。系统结合本地文件哈希与已完成选择的检查点核验版本。
这不能证明服务器已经收到附件，也不能证明用户随后换选了同名文件时内容仍相同。人工复核应再次检查附件。

页面未填完时也可“接管并处理当前页面”，用于登录、验证或未支持控件。
处理后先核实提交状态、记录版本和附件，再“核验后重新接管”。未知提交结果不能自动重试。

## 存储与范围

真实运行目录必须位于系统 checkout 外。它保存所选 PDF 副本、答案、运行检查点和浏览器 profile。
真实与合成目录不能互用。答案 helper 使用已有固定版本；[许可证与来源](../src/career_evidence_graph/_vendor/README.md)保持不变。
问题同义判断的模型调用未启用；同义复用限于已确认的固定别名。岗位简历生成使用已授权 Codex，见[通用流程](generic-application-worker.md)。不明确的问题保留待补充。
本次接入不改变职业图、Skill 评分或职业验证里程碑。

## 历史验证边界 — 2026-10-10

真实页面只读检查已通过。它确认标签和页面身份，未发送个人信息或附件。
