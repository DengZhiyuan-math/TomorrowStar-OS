# 完整目录召回与固定资料包（P03）

普通两库分析复用 P02 的固定 `job_brief`，先查看全部当前轻目录，再读取相关经历
正文与必要关联资料。`application_retrieval` 只找资料，`application_material_packet`
只交付已读原文，不计算匹配分或审核自述可信度。最终匹配消费固定资料包。

## 目录与正文读取

`CareerLibrary.index()` 读取 manifest、目录和注册源描述，不为每岗验证全库正文。
所有当前经历保留入口。目录逐页消费，没有固定 top-K 或项目名称名单；同一经历的
多用途选择合并。超长目录项以相同候选 ID 分片，保留字符范围和重叠上下文，全部
片段读完才记目录完成。检索方向覆盖全部原子要求及独立业务目标、工作产出。

托管正文的索引未完成或目录只有标题时，程序先按 ID 回退读取正文，把实际内容
交给目录召回；读不到时停止为 `retrieval_execution_incomplete`，不判不相关。
旧目录有实质摘要或确认事实时标记 `legacy_context`，这不冒称它已成为 P01 的
`ready` 派生索引。只有标题的旧条目同样需要正文回退。

按需读取使用现有 `snapshot_for_analysis()`。选定经历的补充资料与合法关联 ID
自动展开，循环与重复 ID 合并。未知关联、缺失材料、哈希错误或未完成导入明确
保留失败状态。生成简历和历史材料仍排除。索引 pending 本身不把成功读到的完整
正文变成失败；实际缺失的必要资料仍会阻止交付。

`requested_candidate_ids` 保留调用方选择，`selected_candidate_ids` 保存包含关联
的实际读取集合。分析结果的 `retrieval.selected_candidate_ids` 保持原显式选择语义，
另以 `read_candidate_ids` 表达展开后的集合。补查排除整个已读集合。

旧的 100 条选择和 512 KB 总证据限制已移除。逐文安全读取、版本绑定与符号链接
防护保留；单文超安全界限时显式失败，不截断、不转为能力缺失。已保存 P01 正文
即使没有旧 source registry 也走轻目录入口。没有托管正文的历史 manifest API
保留原兼容行为；未接两库的底层 raw 分析保持旧契约。

## 分段交付

资料包 API 为 `prepare_material_packet()`，返回匹配输入快照和固定 `material_packet`。
普通流程保存版本内的 `material-packet-N/` 阅读记录，最后保存 `material-packet.json`。
真实正文、JD、阅读结果与内部定位只放私有工作空间。

短资料完整复用，不增加阅读模型调用。超出资料预算的集合逐来源、逐 UTF-8 范围
读取，边界保留重叠上下文。阅读模型仅提取与要求或业务目标有关的原文，不改写、
算分、推断缺失或重解岗位。每个片段保存输入、Schema、原始输出及范围摘要；即使
某片段没有相关内容，也保留已完成读取记录。

程序核验摘录的来源 ID、精确原文、绝对字符范围、原字段边界、要求序号和业务
目标适用范围。正文与补充材料保持真实换行，标题、责任、状态及来源上下文独立
保存在 `record_context`，并绑定来源修订。摘录保留完整句上下文；非连续片段不能
拼成一条虚构引文。匹配引用的字符偏移映射回原始来源。

当前资料投影预算为 60 KB，阅读片段预算为 24 KB，边界重叠 256 字符；单独阅读
请求与最终匹配请求各自检查完整输入预算。这些是有界执行参数，不是相关性阈值或
事实可信度分数。所有片段成功后，相关摘录若仍无法完整放入资料包或匹配请求，
会明确执行未完成；不能沿用旧的前缀截断后给出完整分数。输入已声明截断、遗漏
或未读范围时，也不能被重新包装为完整资料包。

资料包绑定岗位、固定要求、业务目标、来源修订与原文摘要。补充读取时，未变化
且作用域相同的已成功片段可复用；失败保留，当前目录不隐式重试。显式刷新创建新
版本。基础信息事实完整保留，不能为了职业正文挤掉或截断语言、学历等已确认事实。

## 完成状态与消费边界

| 结果 | 含义 |
| --- | --- |
| `retrieved` | 已完成查找和必要读取，交付事实与原文供匹配 |
| `information_insufficient` | 查找和读取完成，仍没有形成该要求判断所需的资料 |
| `retrieval_execution_incomplete` | 必要资料不可读、未读完、输入已截断、引用错误或预算无法完整容纳；不产出匹配分 |

资料读取完整性与模型解释正确性分开。范围覆盖、Schema 和哈希不能证明语义召回
没有遗漏。公开测试使用合成及变形案例；真实私人案例和真实模型质量仍需单独接受。

匹配只消费资料包中的固定原文投影，不再次截断。写作主上下文与
终审复用整体资料包；分经历写作者仅收到其分配来源的资料包子集，片段指纹只绑定
相应事实，不因其他经历或读取收据变化全局失效。真实缺少某类事实时提出具体补充
读取，不自行重扫全库。
本步没有完成 P04 的全部受控推断或 P05 的完整写作重构，也没有宣称旧材料的全部
当前性规则已改完。P06–P08 的 Prism、ATS、局部版本和安装接受保持各自范围。
