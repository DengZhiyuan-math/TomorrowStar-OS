## 五、会影响复用选择的源码发现

1. **“review / dry-run”不一定是填写后人工提交。** GodsScion 的 `stop_before_submit=True` 会丢弃申请；`pause_before_submit` 是批准后由 bot 提交。Pickle-Pixel/ApplyPilot 的 dry-run 修改 prompt，输出仍可含 `RESULT:APPLIED`；iknalos/ApplyPilot 的禁提交也主要依赖 prompt。不要把这些状态直接映射为当前项目的人工 Submit 或已投递回执。[GodsScion](https://github.com/GodsScion/Auto_job_applier_linkedIn/blob/e0b2401a7a7b333eab0b518e80be5285c3ee85c5/runAiBot.py)、[ApplyPilot prompt](https://github.com/Pickle-Pixel/ApplyPilot/blob/4a8d521f67f5139811c0a910ef37410f8e6d836a/src/applypilot/apply/prompt.py)。

2. **失败重试与雇主收件需要分开。** Abhishek 的 Lever adapter 点击后未见特定错误便可记 success；devdattatalele 的引擎包含最多三次提交尝试。Jobops 值得参考的是一次性 permit、intent 与 `SUBMIT_UNKNOWN`，但其 README 也明示生产浏览器 runtime composition 未完成。[Lever adapter](https://github.com/AbhishekMandapmalvi/AutoApply/blob/053071ba1bba5733b522d78c3d645002d817e55a/bot/apply/lever.py)、[提交引擎](https://github.com/devdattatalele/auto-apply/blob/be05095da900ef531ac8f7f47005e06be922b774/lib/engine.mjs)、[Jobops](https://github.com/yuyao-wang/Jobops/blob/643f489936e07494941d58433da82826ed224ae8/core/application_engine.py)。

3. **本地存储不等于本地推理。** ApplyAI 固定请求 OpenAI；秒填鸭将个人信息及字段上下文发给配置的模型；geckguy 的 OpenCode Go 默认是云网关。Offlyn 的 Ollama 客户端默认 localhost，有完整 Chrome/Firefox 源码，但本次未完整审计其所有网络与提交路径。[ApplyAI 请求](https://github.com/muhammad-saadd/applyai/blob/d4a97b5643aa219592883a43b068fc18dff94678/utils/ai.js)、[秒填鸭 matcher](https://github.com/kalinplus/auto-filler/blob/6a5443c57e840066761ef5c66f6273a30cc7e8c7/utils/matcher.ts)、[OpenCode Go](https://github.com/geckguy/AutoApply/blob/6c5fbc42833278acaa45981e86b5d99ae97d77a0/backend/services/opencode.py)、[Offlyn Ollama](https://github.com/offlyn-ai/offlyn-apply/blob/6179317448bcaf8c04dbdf50905771b98d7af93a/apps/extension-chrome/src/shared/ollama-client.ts)。

4. **附件支持要按代码区分。** Porter 的 Resume 是 URL，scanner 排除 file/checkbox/radio，且只扫描 input/textarea；FoxiFill 明确跳过 file。ApplyAI 要求人工上传。秒填鸭虽有 file/DataTransfer 路径，README 的附件拖拽仍列 TODO，不能据此承诺完整端到端支持。[Porter scanner](https://github.com/M-SaaD-H/porter/blob/5d7222239edc48f68a514a23170f22dac307517b/src/scanner.ts)、[FoxiFill filler](https://github.com/FoxiFill/foxifill-extension/blob/fa674ade9025017b3355eebab89fa3429e9e6cf2/src/content/form-fill.ts)、[秒填鸭 content](https://github.com/kalinplus/auto-filler/blob/6a5443c57e840066761ef5c66f6273a30cc7e8c7/entrypoints/content.ts)。

5. **云服务与公开源码的能力范围不同。** Browser Use Cloud 本身不开放源码；Stagehand、Skyvern、Steel 均要分别看本地组件、模型与托管服务；Firecrawl 默认自托管栈不包含其云产品全部动作能力。[Browser Use Cloud](https://github.com/browser-use/browser-use/blob/ccd22fef47a1a36e0c4596fef5db73a5117b9d06/CLOUD.md)、[Stagehand v4 本地浏览器](https://github.com/browserbase/stagehand/blob/10418f98831285b3cddca5328c8013a94f22672a/packages/docs/v4/configuration/browser.mdx)、[Firecrawl 自托管](https://docs.firecrawl.dev/contributing/self-host#self-hosted-feature-support)。

6. **可见仓库不保证构建完整。** 本文 Browser MCP 专指 `BrowserMCP/mcp`，不是 Microsoft Playwright MCP 或其他同名项目。它的 README 明示依赖未公开 monorepo 类型和工具，当前不能独立构建，故保留为部分源码参考。[README](https://github.com/BrowserMCP/mcp/blob/9db12f2b4f61294f0bc11708986abc47db539d6c/README.md)、[workspace 依赖](https://github.com/BrowserMCP/mcp/blob/9db12f2b4f61294f0bc11708986abc47db539d6c/package.json)。

7. **许可必须对应组件与 revision。** OmniParser 根 LICENSE 是 CC-BY-4.0，README 却有 MIT 徽章，检测和 caption 权重又分许可；这里将它列为许可待澄清候选。Automa 的 business、Bitwarden 的 bitwarden_license 和 UI.Vision 的 XModules 另有边界。GodsScion 当前 MIT，NOTICE 仍声明早期发布属于 AGPL。[OmniParser LICENSE](https://github.com/microsoft/OmniParser/blob/354021201345a96178360b28733573e27269f2de/LICENSE)、[OmniParser 模型说明](https://github.com/microsoft/OmniParser/blob/354021201345a96178360b28733573e27269f2de/README.md)、[GodsScion NOTICE](https://github.com/GodsScion/Auto_job_applier_linkedIn/blob/e0b2401a7a7b333eab0b518e80be5285c3ee85c5/NOTICE)。

8. **维护与数据流要看具体实现。** LaVague 最近 push 为 2025-01，默认 telemetry 包含目标/动作/URL/HTML来源，README 给出 `LAVAGUE_TELEMETRY=NONE`；TagUI 上游已停止官方支持但仓库未归档。Chrome DevTools MCP 默认工具统计可用 `--no-usage-statistics` 关闭，性能工具的 CrUX URL 请求另用 `--no-performance-crux`。这不是本次启用行为。[LaVague](https://github.com/lavague-ai/LaVague/blob/9024bb832c40291cd012916757f27ef60469b22d/README.md)、[TagUI](https://github.com/aisingapore/TagUI/blob/7508625e815913f691598295817b9953d101e319/README.md)、[Chrome DevTools MCP](https://github.com/ChromeDevTools/chrome-devtools-mcp/blob/2777fa05b296cdb51507e6fd33ae05c06fe0b9e7/README.md)。

9. **抓取、语义解析和执行的正确性判据不同。** Markdown 正文不是完整表单；相似 DOM 元素不代表同一问题；`confidence=high` 也可能只是代码赋值（秒填鸭长文本路径）。BrowserGym 适合研究固定任务和动作日志，benchmark 分数仍不是 ATS 成功率。[秒填鸭匹配](https://github.com/kalinplus/auto-filler/blob/6a5443c57e840066761ef5c66f6273a30cc7e8c7/utils/matcher.ts)、[BrowserGym](https://github.com/ServiceNow/BrowserGym/blob/e71419aef5759a11cb7896a26c36e5f7e92d82b2/README.md)。

## 七、对当前项目的筛选判断

现有 Playwright/Cua 执行链适合继续承担确定性控件操作。最有价值的增量资料是：Porter/Bitwarden 的字段提取规则；FoxiFill 的映射审阅/撤回；Stagehand 的语义定位与确定性值分开；geckguy 的 Next 控件过滤；Jobops 的 intent/unknown 模型；BrowserGym 的固定任务判据。以上为结合现有架构作出的工程推论。

通用框架不会自动提供可确认的个人答案、逐岗位批准的简历文件、未知结果核验或雇主回执。若后续需要比较，可复用既有合成页面检验 iframe、自定义 combobox、文件附件、页面更新、暂停与读回，再决定是否引入新依赖；本次未执行该实验。
