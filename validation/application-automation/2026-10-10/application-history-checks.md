# 投递历史检查回归

2026-10-10。仅记录合成检查；真实岗位及个人填写报告留在私有运行目录。

## 规则

- 原记录非准备投递时，禁止进入自动流程。
- 复用已有 URL 校验与历史记录。Lever、Greenhouse、Ashby 的已识别岗位链接别名不产生新岗位。
- 普通通用链接保留查询参数及片段；不合并不同查询中的岗位。
- 同公司、同岗位名称且至少一条链接缺失或无效时，暂停核实是否重复。
- 名称只做 Unicode、大小写、空格和标点归一化，不推断同义词。
- Unknown Company / Unknown Role 等占位名称不构成名称身份。
- 同公司其他名称的历史记录显示为核对提示，不直接判断同一岗位。
- 生成简历、准备批次、恢复、每次浏览器填写或附件选择，以及人工接管前均核查新鲜记录。
- 恢复只暂停受影响岗位。同步继续使用原记录版本检查，保留并发编辑与待同步结果。
- 最终提交与招聘方接收仍为不同状态，自动填写不更新为已投递。
- 已确认 GitHub / LinkedIn URL 复用明确的 profile 标签；不与通用个人网站问题混同。

缺少链接、岗位 ID 或可靠名称的旧记录不能自动证明同一岗位或从未申请。
同公司不同岗位名称需结合实际岗位 ID、旧记录或用户核验。
合成通过不证明真实表单的自动保存、附件接收或最终申请成功。
