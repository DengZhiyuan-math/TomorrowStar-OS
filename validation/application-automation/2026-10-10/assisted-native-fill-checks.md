# 真实页面辅助填表验证

2026-10-10。运行详情和个人数据仅保存在选定私有 workspace。

| 阶段 | 观察结果 | 证据边界 |
| --- | --- | --- |
| 独立 worker 自动填写 | 未核验的草稿保存被拦截，岗位暂停，页面保留 | 自动保存尚未通过 |
| 现有原生页面接管 | 填写已确认的 URL、国家、来源并上传批准 PDF | agent-browser 辅助操作，不是自动 worker 验收 |
| 附件回读 | 选择的文件版本与 worker 绑定一致；上传 HTTP 204；附件挂接返回无 GraphQL errors | 草稿附件已保存，不是投递回执 |
| 姓名补保存 | 上传后的服务端回读中姓名仍为空；原生重新编辑及 blur 后保存成功 | 页面显示不等同于服务端保存 |
| 最终必填回读 | 7 个必填项均有值，与批准信息和原生选项对应；无表单错误 | 只验证填表和草稿保存 |
| 最终提交 | 请求记录无 Submit 操作，未声明已提交或已接收 | 用户保留最终提交控制 |
